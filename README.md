# Neural Network Lab

Practical exploration of neural networks using TensorFlow/Keras, with applications to credit-risk modelling.

## Overview

This project explores the development and evaluation of neural networks for structured/tabular data, using unsecured consumer-loan default prediction as the primary application.

The goal is to understand neural network fundamentals and assess their potential value in a credit-risk modelling context.

## Objectives

- Understand neural network architectures and fundamentals.
- Implement feedforward neural networks using TensorFlow/Keras.
- Explore activation functions, loss functions, and optimisers.
- Apply regularisation techniques such as dropout and early stopping.
- Address class imbalance in binary classification.
- Evaluate model discrimination and probability calibration.
- Compare neural networks with traditional models such as Logistic Regression and Gradient Boosting.

## Application: Credit Risk

The practical application focuses on predicting default risk for unsecured consumer loans.

Key areas include:
- Data preparation and feature engineering.
- Model training and validation.
- Probability of Default (PD) estimation.
- Model evaluation using ROC-AUC, Gini, KS, Brier score, and calibration analysis.

- Python 3.11

- NumPy and pandas
